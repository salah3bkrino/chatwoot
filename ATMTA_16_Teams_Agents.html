2. إدارة الوكلاء

2.1 إضافة وكيل جديد

  1. اذهب إلى Settings > Team
  2. انقر Add Agent أو + Invite
  3. أدخل بريده الإلكتروني
  4. حدد الدور (Agent / Supervisor / Admin)
  5. اختر الفريق الذي ينتمي له
  6. اضغط Send Invite

سيتلقى الوكيل رسالة بريد إلكترونية بتفاصيل الدخول.

2.2 تعديل بيانات الوكيل

البياناتالوصفالأهمية

البريد الإلكترونيبريد الدخولحساس جداً

2.3 الحالات (Status)

الحالةالمعنىيقبل محادثات؟
Online 🟢متاح وجاهز✅ نعم
Busy 🟡مشغول لكن متصل❌ لا (اختياري)
Away 🟠بعيد عن الكمبيوتر❌ لا
Offline 🔴غير متصل❌ لا
نصيحة: تغيير الحالة
الوكيل يمكنه تغيير حالته مباشرة من القائمة العلوية. استخدم "Busy" عندما تحتاج فترة راحة سريعة.

2.4 حذف وكيل

  • اذهب إلى Settings > Team
  • اختر الوكيل
  • انقر More Options (...)
  • اختر Delete
  • تأكد الحذف
تحذير: الحذف نهائي
حذف الوكيل يحذف جميع بياناته أيضاً. قبل الحذف، قم بتصدير بيانات الوكيل إذا كنت بحاجة لها.

3. إدارة الفريق

3.1 إنشاء فريق جديد

  1. اذهب إلى Settings > Teams
  2. انقر Create Team
  3. أدخل اسم الفريق
  4. أضف وصفاً (اختياري)
  5. أضف الوكلاء الأعضاء
  6. اضغط Create

3.2 أمثلة الفريق

3.3 إضافة وكيل للفريق

  1. افتح الفريق
  2. انقر Add Member
  3. اختر الوكيل من القائمة
  4. احفظ

3.4 إعدادات الفريق

الإعدادالوصفالمثال

3.5 حذف فريق

قبل الحذف:

  • أنقل جميع الوكلاء إلى فريق آخر
  • أغلق أو أعد تسليم المحادثات المفتوحة
  • احفظ أي بيانات مهمة

بعدها:

  1. اذهب إلى Settings > Teams
  2. اختر الفريق
  3. انقر Delete
  4. تأكد الحذف

4. إدارة الأسناد (Assignment Management)

4.1 أنواع الأسناد

1) الأسناد اليدوي (Manual Assignment)

الوكيل أو الفريق ينقل المحادثة يدويّاً:

  • افتح المحادثة
  • انقر على اسم الوكيل الحالي
  • اختر وكيل/فريق جديد
  • أضف تعليق (اختياري)
  • اضغط Assign

2) الأسناد التلقائي (Auto Assignment)

النظام يسند تلقائياً بناءً على القواعل:

  • Round Robin: توزيع دوري
  • Least Busy: أقل مشغول
  • Skill-based: بناءً على التخصص

4.2 إعدادات الأسناد التلقائي

  1. اذهب إلى Settings > Inbox
  2. اختر البريد الوارد
  3. انتقل إلى Auto Assignment
  4. فعّل Enable Auto Assignment
  5. حدد الاستراتيجية
  6. حدد الفريق/الوكلاء
  7. احفظ

4.3 استراتيجيات الأسناد

الاستراتيجيةالوصفالأفضل لـ
Round Robinتوزيع متساوي بالتناوبالفريق المتساوي الخبرة
Least Busyأسند لأقل مشغولالتوزيع العادل
Randomتوزيع عشوائيالأحمال المتغيرة
Skill-basedحسب التخصصالمحادثات المعقدة

4.4 قائمة الأسناد (Assignment List)

انظر جميع المحادثات المسندة للوكيل:

  • اذهب إلى اسم الوكيل في الشريط الجانبي
  • انقر على محادثة لتفتحها
  • انظر إلى عدد المحادثات
نصيحة: توازن الحمل
استخدم "Least Busy" لضمان عدم الإفراط في تحميل وكيل واحد.

5. صلاحيات تفصيلية (Detailed Permissions)

5.1 صلاحيات Admin

  • ✅ إضافة/حذف الوكلاء
  • ✅ إدارة الفريق
  • ✅ تغيير الإعدادات العامة
  • ✅ عرض جميع الإحصائيات
  • ✅ إدارة التكاملات
  • ✅ إدارة الأتمتة
  • ✅ حذف المحادثات

5.2 صلاحيات Supervisor

  • ✅ عرض إحصائيات الفريق
  • ✅ إدارة الفريق المسند
  • ✅ الرد على المحادثات
  • ✅ إعادة تسليم المحادثات
  • ❌ إضافة وكلاء (Admin فقط)
  • ❌ تغيير الإعدادات الأساسية (Admin فقط)

5.3 صلاحيات Agent

  • ✅ الرد على المحادثات المسندة
  • ✅ إضافة ملاحظات
  • ✅ إغلاق المحادثات
  • ✅ عرض الإحصائيات الخاصة
  • ❌ رؤية إحصائيات الفريق
  • ❌ إدارة الوكلاء
  • ❌ تغيير الإعدادات

6.1 تعديل الملف الشخصي

  2. اختر Profile Settings
  3. عدّل البيانات المطلوبة
  4. احفظ

  1. انقر على صورتك
  2. اختر Change Password
  3. أدخل كلمة المرور القديمة
  4. أدخل كلمة المرور الجديدة (مرتين)
  5. احفظ

7. أفضل الممارسات

7.1 إدارة الفريق

  • ✅ استخدم أسماء واضحة للفريق
  • ✅ نظّم الفريق حسب الاختصاص
  • ✅ راجع عضوية الفريق شهرياً
  • ✅ حافظ على توازن الأحمال
  • ❌ لا تجعل فريق يحتوي على وكيل واحد فقط
  • ❌ لا تترك الوكلاء في فريقين في نفس الوقت

7.2 الأسناد الفعال

  • استخدم الأسناد التلقائي (Round Robin أو Least Busy)
  • راقب توازن الحمل
  • أعد التسليم إذا كان الوكيل مشغول
  • علّم الوكلاء بقواعل الأسناد

7.3 الإشراف والمراقبة

  • راجع الإحصائيات يومياً
  • أعط تغذية راجعة منتظمة
  • احتفل بالإنجازات
  • ساعد الوكلاء على التحسن

7.4 أمان وخصوصية

  • لا تشارك بيانات الدخول
  • استخدم كلمات مرور قوية
  • غيّر الدور عند الحاجة
  • احذف الوكلاء غير النشطين
