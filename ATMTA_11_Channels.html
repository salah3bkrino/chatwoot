2. Live Chat Widget

2.1 المميزات

  • ✅ دردشة مباشرة على الموقع (في الوقت الفعلي)
  • ✅ قابل للتخصيص (الألوان، الموضع، الرسائل)
  • ✅ يظهر/يختفي تلقائياً حسب توفر الوكلاء
  • ✅ دعم الملفات والصور
  • ✅ نموذج ما قبل المحادثة (Pre-chat Form)
  • ✅ يعمل على الهاتف والكمبيوتر

2.2 خطوات التكامل

  1. أنشئ صندوق وارد جديد ونوع القناة Website
  2. انسخ Website Token من إعدادات الصندوق
  3. أضف الكود في <head> موقعك
  4. اختبر الـ Widget على موقعك

2.3 الحد الأقصى

  • عدد الرسائل: بلا حد (تُخزن في قاعدة البيانات)
  • حجم الملف: حتى 100 ميجابايت
  • المستخدمين المتزامنين: بلا حد

3. البريد الإلكتروني (Email)

3.1 طرق التكامل

الطريقةالوصفالإعداد
IMAP/SMTPربط حساب إيميل عاديمعقد (بحاجة IMAP)
Forward Emailتوجيه الإيميلات تلقائياًبسيط جداً
Google Workspaceتكامل مع جوجلمتوسط
Microsoft 365تكامل مع أوتلوكمتوسط

3.2 IMAP/SMTP - الإعداد

مثال لـ Gmail:

  • IMAP Host: imap.gmail.com
  • IMAP Port: 993 (SSL)
  • SMTP Host: smtp.gmail.com
  • SMTP Port: 465 (SSL)
  • Username: your-email@gmail.com
  • Password: App Password (ليس كلمة المرور العادية)

3.3 Forward Email - الطريقة الأسهل

  1. في Chatwoot، اختر Email Channel
  2. ستحصل على بريد Chatwoot فريد (مثل: inbox-12345@chatwoot.example.com)
  3. في إيميل عملك، أضف Forwarding Rule
  4. وجّه رسائل العملاء لـ بريد Chatwoot
  5. كل رسالة ستظهر تلقائياً كمحادثة جديدة!
نصيحة: استخدم Forward Email
الطريقة الأسهل والأكثر موثوقية هي Forward Email. لا تحتاج لتخزين كلمات مرور.

3.4 الحد الأقصى

  • حجم البريد: حتى 25 ميجابايت
  • عدد المرفقات: بلا حد

4. WhatsApp Cloud API

4.1 المميزات

  • ✅ WhatsApp رسمي من Meta
  • ✅ أرقام المرسل الموثقة (Business)
  • ✅ قوائم الرسائل (Message Templates)
  • ✅ رسائل تلقائية مُدرجة
  • ✅ إحصائيات تفصيلية
  • ❌ المراسلات الجماعية (فقط 1-to-1)

4.2 المتطلبات

  • حساب Facebook Business
  • رقم هاتف موثق (WhatsApp Business Account)
  • API Token من Meta
  • Phone Number ID من Meta

4.3 خطوات الإعداد

  1. انتقل إلى Facebook Business Manager
  2. أنشئ WhatsApp Business Account
  3. تحقق من رقم الهاتف
  4. احصل على API Token و Phone Number ID
  5. في Chatwoot، أنشئ قناة WhatsApp وأدخل البيانات

4.4 الحد الأقصى

  • الرسائل المرسلة يومياً: يعتمد على رقم الهاتف (عادة 1000+)
  • حجم الملف: 100 ميجابايت
  • أنواع الرسائل: نص، صور، فيديو، مستندات، موقع
تحذير: الموافقة من Meta
قد يستغرق التحقق من Meta عدة أيام. تأكد من أن معلومات عملك صحيحة.

5. Facebook و Instagram

5.1 Facebook Messenger

الإعداد:

  1. أنشئ صفحة Facebook Business
  2. في Chatwoot، أنشئ قناة Facebook
  3. وصّل صفحتك عبر OAuth
  4. سيبدأ استقبال الرسائل تلقائياً

5.2 Instagram Direct Messages

نفس خطوات Facebook. الحساب يجب أن يكون Business Account.

5.3 الحد الأقصى

  • الرسائل: بلا حد
  • الملفات: صور وفيديو فقط

7. API Channel - قناة مخصصة

7.1 ما هي API Channel؟

قناة تسمح باستقبال رسائل من أي مصدر خارجي عبر API REST.

7.2 الاستخدامات

  • تطبيق مخصص خاص بك
  • نظام CRM قديم
  • قناة غير مدعومة حالياً
  • Webhooks من الخدمات الخارجية

7.3 مثال: إرسال رسالة عبر API

POST /api/v1/inboxes/:inbox_id/contacts/:contact_id/conversations { "name": "علي", "email": "ali@example.com", "phone_number": "+966501234567", "message": "السلام عليكم، أحتاج مساعدة" }

8. اختيار القناة المناسبة

8.1 للعملاء الدولين → Live Chat

  • سريع وفوري
  • بلا تطبيق إضافي مطلوب
  • يعمل من الموقع مباشرة

8.2 للعملاء في الخليج → WhatsApp

  • الكل يستخدمه
  • يشعر العميل بأنه يتحدث مع عمل حقيقي
  • سهل الاستخدام

8.3 للعملاء الفنيين → Email

  • للمسائل المعقدة
  • للمرفقات الكبيرة
  • يترك أثر رسمي

8.4 للعلامات التجارية الصغيرة → Facebook + Instagram

  • كل العملاء لديهم حساب
  • تسويق مدمج
  • مجاني تماماً

9. أفضل الممارسات

9.1 استخدم قنوات متعددة

لا تقتصر على قناة واحدة! العملاء يختارون القناة المريحة لهم.

9.2 استقبل من كل مكان

  • Live Chat على الموقع ← العملاء الجدد
  • WhatsApp ← العملاء المحليين
  • Email ← الحالات الرسمية
  • Facebook ← للعلاقات العامة

9.3 تدريب الفريق على كل قناة

كل قناة لها أسلوب مختلف. تأكد من أن الفريق يعرف الفروقات.

9.4 مراقبة الأداء

  • أي قناة لها أعلى معدل استجابة؟
  • أي قناة لها أعلى معدل حل؟
  • أي قناة تحتاج تحسين؟
